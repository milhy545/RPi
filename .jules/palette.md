## 2026-10-27 - Dynamic Icon Translation and Accessibility
**Learning:** When generating buttons with visual icons dynamically (like the theme toggle `🌓`), using static `aria-label` or `title` assignments will result in poor screen reader experience, as translations won't automatically update when the language is toggled. Additionally, injecting innerHTML like `themeBtn.innerHTML = '🌓'` reads the unicode character inconsistently on screen readers.
**Action:** Always use `<span aria-hidden="true">icon</span>` to wrap the raw visual icon so it's skipped by screen readers. For accessible labeling and titles, rely on the data attributes `data-i18n`, `data-i18n-attr="title"` and `data-i18n-attr="aria-label"` (if possible via HTML) or directly assign the translation using `L()` and `ariaText()` during element creation, but ensure it receives the correct dataset attributes so the dynamic translation function (`applyLang()`) can find and update it when the user switches languages.
